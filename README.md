# rogerhutchin.gs

A one-page freelance and consulting website built with Astro and deployed as a static site to GitHub Pages.

## Requirements

- Node.js 24 LTS
- pnpm 12

## Install

```sh
pnpm install --frozen-lockfile
```

## Develop

```sh
pnpm dev
```

## Build

```sh
pnpm build
```

Astro writes the production site to `dist/`.

## Preview

```sh
pnpm preview
```

The preview serves the generated production output locally.
